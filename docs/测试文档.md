# PromptForge 测试文档

> 面试笔试 Demo · 测试方案与执行记录  
> 文档版本：1.0 · 日期：2026-11-27

## 1. 测试目标

验证 PromptForge 在笔试演示场景下是否能够稳定完成：

1. 主页输入/模板 → 生成模式选择 → 生成任务。
2. DeepSeek / 千问单模型与双模型赛马。
3. 完整全栈项目解析、完整性校验、Mock 兜底和十维评分。
4. 后台任务在离开页面后继续执行、任务取消和失败提示。
5. 预览沙箱、源码目录树、版本切换、在线修改和版本追加。
6. ZIP 下载、发布静态预览、取消发布、刷新保留前端状态。
7. 基础安全、并发浏览器隔离和异常路径。

## 2. 测试范围

### 2.1 本轮包含

- Django 启动、配置检查、迁移、测试数据库。
- 主页与工作台核心交互。
- 后端 API、任务状态机、生成/修改流程。
- 解析器、完整性校验、十维评分。
- 预览沙箱、发布页 CSP、URL 存储。
- 项目列表滚动、展开、版本操作。
- 异常处理（模型超时、缺少 Key、格式错误、任务删除）。
- 双浏览器并发抽测。

### 2.2 本轮不包含/生产待测

- 真实阿里云 ECS + PostgreSQL + Gunicorn + Nginx 联调。
- 正式版本的独立环境全栈发布（当前仅静态预览）。
- 登录、RBAC、租户配额、计费、审计。
- 大规模并发、压力测试、长时间稳定性测试。
- 生成项目的真实后端启动、迁移、API E2E。
- Firefox/Safari 全量兼容。
- 正式的多机多 worker 任务取消一致性。

## 6. 缺陷回归记录

| ID | 问题 | 原因 | 修复/验证 |
| --- | --- | --- | --- |
| BUG-01 | 预览页主体空白、交互缺失 | 普通 JS 含 `createElement` + HTML 模板字符串被误判为 JSX，Babel 延迟执行导致 DOMContentLoaded 失效 | 收紧 JSX 判定；历史预览读取时自动还原 |
| BUG-02 | 全栈项目只有 requirements/DEPLOY/前端预览 | 模型漏 END_FILE，严格解析器把全部文件吞进 requirements | 容错按下一个 FILE/PREVIEW 标记拆分；完整性校验 + Mock 兜底 |
| BUG-03 | 千问显示“项目结构不完整，Mock 兜底” | Qwen 90 秒读超时，内容为空被误判为结构问题 | `QWEN_BACKEND_TIMEOUT=180`，状态区分超时/格式/结构 |
| BUG-04 | 项目多时卡片压缩，展开看不到版本 | flex 子项默认 shrink，列表内卡片被压扁 | `flex: 0 0 auto`；列表独立滚动；展开自动定位 |
| BUG-05 | 发布页刷新丢 localStorage 状态 | 沙箱 opaque origin 只有内存 shim | 存储镜像到 `__pf_store` URL 参数 |
| BUG-06 | 运行中任务删除需要点两次 | 删除请求同步等待模型 HTTP close | 事件先置位，异步关闭 socket；前端乐观移除 |
| BUG-07 | 在线修改离开页面丢失 | 修改是同步 HTTP，页面卸载中断 | 修改改为后台 `GenerationJob`，主页任务栏 + 工作台恢复 |
| BUG-08 | 赛马总是 DeepSeek，评分维度不足 | 六维、预览导向、缺需求/状态/性能覆盖 | 十维 63 检查、需求覆盖、可展开评分详情；统计读取全部任务 |

## 7. 未覆盖项与风险

| 项 | 风险 | 建议 |
| --- | --- | --- |
| 独立环境全栈发布 | 当前只发布静态预览 | 按说明文档第 9 节实现构建/容器/子域名/数据库 |
| PostgreSQL + Gunicorn + Nginx | 本地只验证 SQLite/runserver | 在阿里云 ECS 执行部署清单 |
| 真实 Qwen 180 秒长任务 | 可能仍受上游延迟影响 | 观察日志；必要时提高 `QWEN_BACKEND_TIMEOUT` 或换模型 |
| 多 Gunicorn worker 取消 | 取消事件为进程内注册表 | 使用数据库状态标记 + 跨进程停止机制 |
| 账号/权限/配额 | 无认证，client_id 不是身份 | 接入登录、RBAC、限流、租户隔离 |
| 生成后端运行时 | 未启动生成项目 | 增加容器运行环境和 API 健康检查 |
| 自动化 E2E | 没有正式 Playwright CI 套件 | 将本轮 E2E 用例固化为 CI |
| 跨浏览器 | 只在 Edge 抽测 | 补 Chrome/Firefox/Safari 和移动端 |

## 8. 测试结论

演示版核心链路通过：

- 模式选择、推荐、单模型、赛马。
- 全栈项目生成、容错解析、完整性兜底、十维评分。
- 后台任务、离开页面继续、任务取消。
- 工作台预览/源码、在线修改、版本追加。
- ZIP 下载、静态发布、CSP 隔离、刷新状态。
- 项目列表滚动和版本展开操作。

当前不建议把发布能力宣传为“正式全栈上线”：它只是当前域名下的静态预览，正式版本必须生成独立运行环境并部署完整前后端。该差异已在说明文档和验收清单中标注为生产 Gap。

**退出标准建议**：P0/P1 用例全部通过；P0 缺陷为 0；已知限制有明确替代方案和文档说明。本轮演示版满足该标准。
